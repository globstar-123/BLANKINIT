# 📄 Blank Page Maker

A simple, elegant web application for creating custom static HTML pages with live preview and fullscreen viewing.

## ✨ Features

- **🎨 Full Customization**
  - Background color picker
  - Text color picker
  - Font size adjustment (8-72px)
  - Font family selection (6 options)
  - Custom page title and content

- **👁️ Live Preview**
  - Real-time preview updates as you type
  - Side-by-side editor and preview panels
  - Professional preview styling

- **🖥️ Fullscreen Mode**
  - View your page in fullscreen
  - Press ESC or click close button to exit
  - Immersive viewing experience

- **💾 Download & Share**
  - Export your page as a standalone HTML file
  - Share with others or host anywhere
  - No dependencies - pure HTML

- **🔄 Auto-Save**
  - Settings are automatically saved to browser storage
  - Your preferences persist across sessions

- **🎯 Reset**
  - Quickly reset all settings to defaults

## 🚀 Getting Started

1. Open `index.html` in your browser
2. Use the editor panel on the left to customize your page
3. Watch the live preview on the right
4. Click "View Fullscreen" to see the full page experience
5. Download your page as HTML when ready

## 📁 Files

- `index.html` - Main HTML structure and interface
- `style.css` - Beautiful responsive styling with gradients
- `script.js` - Interactive functionality and page generation
- `README.md` - This file

## 🎮 How to Use

1. **Edit Title & Content** - Type in the text fields
2. **Customize Colors** - Click the color pickers to choose background and text colors
3. **Adjust Font** - Select font family and size
4. **Preview Live** - See changes instantly in the preview panel
5. **Go Fullscreen** - Click "View Fullscreen" to see your page maximized
6. **Download** - Click "Download HTML" to save your page
7. **Reset** - Click "Reset" to restore default settings

## 💡 Tips

- Your settings are saved automatically to your browser
- Each downloaded file is a complete, standalone HTML page
- The fullscreen view shows exactly how your page will look when downloaded
- Press ESC to exit fullscreen mode quickly
